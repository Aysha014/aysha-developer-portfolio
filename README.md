# Aysha Akter Tisha — Developer Portfolio

A responsive Next.js portfolio starter with project case-study pages.

## Requirements
- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Customize before submission
1. Replace the initials avatar in `app/page.tsx` with your professional photo.
2. Add your resume as `public/resume.pdf`, then add a Resume button in the hero.
3. Check the project descriptions and technology stacks in `data/projects.ts`.
4. Replace each project's GitHub profile link with its exact repository URL if available.
5. Add your phone number only if you want it public.
6. Update education completion year/CGPA and add formal work history if applicable.
7. Adjust skill percentages to reflect your actual proficiency.

## Build and deploy
```bash
npm run build
```
Push the project to GitHub, import the repository at https://vercel.com/new, and deploy.
